# Whisperwood direct prop runtime

This slice promotes the two Packet 001 direct prop anchors with native-PASS
editable evidence into static custom-geometry blocks:

- `aionbound:lantern_post`
- `aionbound:moss_cairn`

The shipping geometry is the exact second native Blockbench export with only
the geometry identifier normalized from `aionforge_ww` to `aionbound`. Shipping
textures are byte-identical to the native evidence inputs.

Block skeletal animation is deliberately withheld. The Lantern Post clips stay
in source evidence, but this slice contains no shipping animation or controller
binding because native clip authoring does not prove supported custom-block
playback. Loot, rewards, structure assembly, world generation, and encounter
behavior are also outside this slice.

The receipt proves static BP/RP and evidence-reference closure only. It does not
prove package admission, BDS load, Bedrock client rendering, animation playback,
controller behavior, multiplayer, physical PS4, or Marketplace readiness.
