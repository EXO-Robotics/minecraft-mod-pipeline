# Skyreach plant product binding

This bounded lane binds the exact native pass-2 geometry and native texture
bytes for ten qualified Skyreach plants to Stable custom blocks and conservative
mountain-or-hills world-generation proxies. It deliberately adds no loot,
acquisition contract, recipes, Script animation, encounter, progression, or
Creative-authority surface. Static source checks do not prove live placement,
rendering, BDS, client, console, Marketplace, or release behavior.
