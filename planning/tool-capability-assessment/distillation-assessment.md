# Distillation assessment

`mccompiler distill-modpack` accepts an authored distillation document, ModIR JSON, a conversion project containing ModIR, or a raw path scanned into preliminary ModIR. Raw scanning clusters only coarse content kinds, triggers, and unsupported hooks; identity, progression, rights, effort, console cost, and player-facing system boundaries require attributable AI/human enrichment.

The deterministic service validates schemas; scores fixed integer dimensions; gates unstable APIs and rights; closes prerequisites; rejects progression cycles; applies effort and static console ceilings; checks progression-stage connectivity; computes a Pareto frontier with stable tie-breaking; emits quarter/deferred scope, risks, pattern coverage, roadmap and manifest; and validates cross-file agreement and hashes. Review adjustments remain attributable and cannot grant rights.
