# Crazy Craft quarter mapping

This maps the preliminary **original category-level replacement** scope; it does not authorize or begin content production.

| System family | Reuse | Extension / novel work | Java evidence inputs | Bedrock strategy | Required tests / risks |
|---|---|---|---|---|---|
| Core state and progression | DoorLock migrations/authorization; Clockwork progression | Party isolation, campaign schema, rollback policy | Version-pinned progression, state and dependency evidence | Dynamic properties plus revisioned state | Two players, reconnect, three restarts, save growth |
| Original odd arsenal and early survival | Item/use/projectile/effect/cooldown primitives | Original weapons, durability, area targeting and feedback | Registrations, callbacks, recipes, assets | Data items plus protected stable-script handlers | Physical aiming, effects, cooldowns, controller; projectile/particle caps |
| Original regional creatures | Spawn/lifecycle/growth primitives | AI archetypes, models, animation, ecology | Entity registrations, goals, spawn conditions, drops | Bedrock components plus bounded scripts | Despawn, density, multiplayer targeting, base-console entity load |
| Original structures and discovery | Static structure/placement architecture | Real templates, discovery and encounter controller | Templates, placement rules, loot/dependencies | Original structures plus bounded placement | Chunk placement, asset sync, save size, exploration soak |
| Original elite ladder | Hit/hurt/death, loot/progression concepts | Elite modifiers, telegraphs and reward integration | Entity/combat/drop/progression evidence | Bedrock elite archetypes | Attribution, scaling, drops, multi-elite stress |
| Original boss and power ladder | Three-phase state machine | Full AI, arena, powers, presentation, persistence | Boss phase, AI, loot, spawn and arena evidence | Original Bedrock bosses plus scripted phases | Real combat, two-player scaling, restart, controller clarity, console load |
| Original controlled chaos finale | Scheduler and state primitives | Budgeted event director, caps, cooldowns, conflict rules | Random-event intent/dependencies | Server-authoritative weighted event table | Four-player soak, p95 script/frame time, entities/particles; highest risk |
| Original postgame mutators | Progression and event-table patterns | Safe combinatorics, opt-in form, migration policy | Modifier/progression evidence | Versioned bounded mutators | Combination matrix, restart, controller, long soak |

Dependency order:

`core state/progression → arsenal → creature archetypes → structure encounters → elites → bosses/powers → chaos → finale → postgame mutators → integration/optimization`

Every family requires original or separately cleared names, art, sound, models, text, and branding. Source behavior evidence may guide category and intent; protected expression must not be copied without rights.
