# Remaining proof gates

## A. Reliable for supported patterns

- Physical-player item use/use-on-block, projectile launch/impacts, effects, cooldowns, block interaction/break, and real forms.
- Player-created state across leave/rejoin and multiple restarts.
- Two-player state isolation, ownership, authorization, attribution and contention.
- Controller navigation, focus and accessibility.
- Long-duration machine/scheduler persistence and asset synchronization.
- Migration from an actual earlier shipped-format build.

## B. Console-ready

- Exact unchanged artifact through intended Realm/delivery flow.
- Minecraft for Windows baseline and Realm upload/restart.
- PS4, PS5, Xbox One and Xbox Series; split-screen and controller-only.
- Four-player stress on base-generation hardware.
- Frame pacing, script timing, entity/particle/geometry/texture/memory budgets, save growth, and long-duration persistence.

## C. Marketplace-candidate ready

- Attributable component-level code, asset, sound, model, texture, branding, trademark, derivative and commercial rights review.
- Original branding/assets where replacement is required.
- Stable API audit; final Creator Tools receipt; clean packages/dependencies.
- Accepted fidelity/redesign records; migration and performance policies.
- Physical qualification evidence and publisher-review materials.
- No experimental/unsupported dependency and no claim that Creator Tools equals approval.

## D. Minimum gate before quarter-scope production

1. Exact edition/version/loader and complete hashed artifact inventory.
2. Legally authorized source/bytecode analysis and human-reviewed identity/progression map.
3. Component rights inventory and originality plan.
4. Physical-client closure of Clockwork item/effect/cooldown/form gaps.
5. Real two-player DoorLock ownership plus restart test.
6. Controller-only Windows/Realm dry run.
7. One base-console performance calibration.
8. Evidence-backed effort/performance costs and rerun distillation at a 60–64 planning budget.
9. Approved integration benchmark results and go/no-go review.
