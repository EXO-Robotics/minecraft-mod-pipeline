# AI reconstruction decision contract

For every extracted feature, the agent must record exactly one decision and its evidence.

| Decision | Minimum evidence | Human approval |
|---|---|---|
| `DIRECT_RECONSTRUCTION` | Recognized Java fact, stable data-driven Bedrock equivalent, generated artifact, schema/static validation, no omitted behavior | Required only for material ambiguity/rights |
| `STABLE_SCRIPT_RECONSTRUCTION` | Stable API catalog match, event/state context, protected handler plan, static API validation, targeted runtime test plan | Required for gameplay/fidelity changes |
| `BEDROCK_NATIVE_REDESIGN` | Source intent evidence, documented lack of direct equivalence, viable stable Bedrock pattern, fidelity/risk comparison | Required before acceptance |
| `ORIGINAL_REPLACEMENT` | Platform or rights blocker, original-design record, provenance separating protected expression, rights review path | Always |
| `DEFER` | Explicit dependency/blocker, impact, prerequisite, and revisit gate | Product owner |
| `RIGHTS_BLOCKED` | Missing/negative component-level rights evidence | Only attributable rights reviewer may clear |
| `UNSUPPORTED` | Catalog/frontend/runtime evidence showing no viable stable implementation, plus rejected alternatives | Product owner acknowledges omission |

Decision sequence:

1. Does a stable data-driven equivalent preserve behavior? Use direct reconstruction.
2. Does stable Script API reproduce it with bounded cost? Use stable-script reconstruction.
3. Can a Bedrock-native design preserve the player experience? Propose a native redesign.
4. Is source expression blocked or unsuitable but the category valuable? Propose an original replacement.
5. Otherwise defer, rights-block, or mark unsupported.

AI may add evidence-backed intent proposals and provenance-bearing IR patches. Accepted intent, fidelity loss, strategy changes, original replacements, rights conclusions, and protected implementation authority require distinct review records. The AI may never promote simulated evidence to physical proof or rights evidence to legal clearance.
