# MacBook-Local Qualification Policy

## Decision

MacBook-local Docker BDS is the authoritative initial exact-package
qualification service for the Crazy Craft pack factory.

Mac Studio BDS remains preserved as optional overflow or independent
replication capacity. It is not a factory-launch prerequisite.

## Rationale

- The MacBook route has executed a real, digest-pinned Stable BDS process.
- The unchanged Trailbound tuple passed exact hashing, safe extraction, pack
  activation, shipped-entrypoint initialization, clean shutdown, same-world
  restart, receipt return, and cleanup.
- Studio SSH and image installation add an unrelated operational dependency.
- Isolated local Docker jobs can run concurrently without changing candidate
  authority.
- A later Studio replication receipt may supplement but does not invalidate a
  valid local receipt.

## Execution rules

The tester:

1. Reads only committed tester-intake messages.
2. Resolves candidates by repository, ref, commit, tree, exact path, size, and
   SHA-256.
3. Uses one immutable candidate per container.
4. Uses unique container, world, port, log, and output identities.
5. Applies CPU, memory, PID, read-only-root, non-root, and no-network controls.
6. Mounts no Java evidence, private oracle, credentials, or unrelated
   repository.
7. Runs exact hashing, package safety, Stable BDS startup/load, available
   fixtures, shutdown, restart, receipt validation, and cleanup.
8. Publishes an append-only result and never edits a product repository.

Initial capacity is two local BDS jobs globally and one active job per pack.
Capacity may decrease when host resource or isolation guards fail.

## Proof boundary

Local BDS qualification does not imply Bedrock client rendering, audible
playback, controller-only interaction, multiplayer, Realm, split-screen,
physical PS4, rights, branding, Marketplace, or release proof.

For Trailbound:

`PLAYER_MUTATED_PERSISTENCE = NOT_RUN_AUTOMATION_HOOK_UNAVAILABLE`

The missing product-specific mutation hook does not invalidate the generic
package-load/restart infrastructure proof.
