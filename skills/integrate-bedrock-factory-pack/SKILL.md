# Integrate Bedrock factory packs

Work only in the INTEGRATION lane. Require an explicit admitted T2 or integration
activation; missing or rejected platform authority means structured `NO_SPAWN`.

## T2 adapter work

Read only admitted callable service contracts and exact platform authority. Do
not read Java evidence or silently expand pack scope. Implement the narrow shared
adapter in its owned repository, run declared local checks, and publish a
hash-bound adapter result. A T2 result is not itself pack-candidate publication
or downstream qualification.

## Segment integration

Consume exact frozen candidate generations without modifying their repositories
or history. Verify hashes before combining them, resolve only explicitly owned
namespace/API conflicts, run integration-local tests and deterministic packaging,
then freeze a new integrated candidate with complete lineage.

Return separate results for adapter implementation, integration-local validation,
and external gates. Do not claim T1, BDS, T10, client, Realms, controller,
split-screen, PS4, Marketplace, or release PASS unless the proper owner produced
an exact receipt.
