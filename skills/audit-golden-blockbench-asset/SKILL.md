# Audit a Golden Blockbench Asset

Operate as a fresh post-freeze visual auditor. You may read the authorized
control set and private originality cases, but you must not modify production or
return control-reference details to its agent.

## Verify the audit packet

Require production and repair process receipts proving the actual authoring
processes ran through the recorded sandbox executor.

Require:

- Frozen candidate commit and exact source/export/package hashes.
- Typed visual-contract, class-profile, proof-contract, and transfer hashes.
- Read-only native round-trip captures and receipts.
- Deterministic export manifests, proof inventory, provenance, and BP/RP fixture.
- Authorized control set, private collision tests, and opaque finding output.
- Audit-local scratch/output roots, authoritative tool versions/commands,
  mutation inventory, and frozen originality-materiality policy.

Reject a dirty or mutable candidate, mismatched hash, incomplete provenance, or
missing lane lineage.

Mount candidate, evidence, and control inputs read-only. Perform rebuilds and
write reports only in the audit-local scratch/output roots. Never write into an
input lane.

## Audit native and proof integrity

Reject flattened UUID-only outliners, fake locator groups, unresolved recursive
references, and hierarchy cycles. Verify representative actual Blockbench
open/save/reopen/native-export receipts. Keep static shape, UI roundtrip, native
export, Bedrock rendering, and PS4 rendering conclusions separate.

Verify RFC 4122-shaped UUIDs and all element, outliner, animator, keyframe, and
texture links. Confirm reopen/save/reopen/export used the exact final model,
showed zero warnings, and displayed all required clips with real keyframes.
Compare source and runtime counts, hierarchy, pivots, locators, identifiers, and
atlas bindings.

Verify every fixed proof's camera, pose, resolution, hash, and honest
`source_type`. Require true silhouette-only and atlas-underlay UV sheets,
player-scale markers, contact poses, and feature-action poses. Ensure a
deterministic renderer uses runtime transforms and atlas-informed materials.

## Run two critique cycles

Cycle 1:

- Model construction, hierarchy, pivots, locators, UVs, animation contacts and
  seams, proof accuracy, collision/bounds, and BP/RP bindings.

Cycle 2:

- Silhouette and proportion, material/texture language, distance readability,
  state communication, presentation originality, and console-conscious cost.

Independently compute all contracted visual metrics. Missing or renamed metrics
fail rather than defaulting to zero. Score silhouette 25%, animation 20%,
material 20%, readability 15%, construction 10%, and originality 10%. Require
each category at least 70 and weighted total at least 80. Originality passes
independently.

Mutation-test that the gates reject broken UUID/link graphs, missing or renamed
metrics, dishonest proof `source_type`, a forbidden timing collision, and an
asset-only candidate containing a fake qualification marker script.

## Audit originality

Check exact identifiers, strings, byte-identical files, geometry signatures,
UV/palette/marking structure, animation timing patterns, silhouette,
presentation sequencing, prompts, commits, caches, and build outputs. Treat the
control asset only as an audit reference, never a quality template.

Apply the frozen private materiality policy to exact durations and repeated
timing tuples. A commonplace duration inside a narrow public contract range is
not automatically distinctive; an exact multi-clip pattern or a value marked
material by the pre-frozen policy is a finding. Do not choose materiality after
seeing which result is convenient. Report copying-prevention evidence and
detected absence separately; preserve uncertainty.

For a repairable finding, return only:

- Opaque finding and public requirement IDs.
- Candidate-observable defect.
- Instruction to change the candidate's current value within its public
  contract range, without identifying the control value.
- Invalidated gates.

Never disclose a control value, image, filename, hash, distinctive description,
private test case, or evidence path.

Before any finding crosses into production, mechanically scan the outbound
packet against control-only identifiers, filenames, paths, hashes, values,
private case IDs, and distinctive descriptions. Bind a passing leak-scan receipt
to the exact outbound packet hash.

## Qualify the frozen asset

Rebuild deterministic exports and packages twice in audit scratch. Both rebuild
hashes must equal the frozen candidate hashes, not merely each other. Run static
validators, Creator Tools on the exact package, Stable and Preview BDS load/summon,
bounded stress, cleanup, and restart as assigned. For asset-only packs require
an explicit `require_script_runtime: false` receipt instead of a fake script.

After any repair, require a new production commit and package hash, then rerun
every affected native, proof, heuristic, originality, lineage, Creator Tools,
and BDS gate.

Return `GOLDEN_VISUAL_CANDIDATE_AUDITED` only when all core gates pass. Keep
desktop client visual review, animation playback, controller readability,
Realm, split screen, physical PS4, Marketplace, and release pending unless
independently executed.
