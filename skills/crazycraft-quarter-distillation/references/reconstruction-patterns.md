# Reconstruction patterns

DoorLock proves or establishes persistent and canonical locations, ownership,
authorization, forms, server authority, migrations, break cleanup, redstone
reconciliation, and fail-closed state validation.

Clockwork Gardens proves or narrowly classifies item actions, projectiles,
effects, cooldowns, event contexts, progression, machines, form-backed
interactions, growth, entity lifecycle, multiphase bosses, runtime tests, and
performance budgets.

For each selected system classify each pattern as reusable, needing extension,
novel, Bedrock-limited, and benchmark-required. Preserve evidence granularity:
synthetic integration is not real-client, multiplayer, or console proof; static
performance policy is not measured console performance.
