# AI processing policy

The private GitHub repository is the authoritative (“gold”) copy of this
project. A local clone is the normal working copy.

The project owner authorizes OpenAI Codex to process repository content as
needed for work explicitly requested in an owner-controlled Codex task. This
includes repository inspection, code generation, testing, review, and
delegation to Codex agents operating within the same authorized task.

This authorization does not make the private repository public and does not
authorize disclosure to unrelated third-party model providers, public
services, or people. Grok and other external providers require a separately
scoped authorization. Credentials, tokens, private keys, evidence-vault
material, licensed source restricted to analysis, personal information, and
unrelated files remain excluded unless explicitly authorized.

The MIT license governs use and redistribution of the project’s licensed
software. It does not itself authorize access to private systems or override
the disclosure boundaries above.
