# Controller-first redesign

Keyboard shortcuts, mouse hover, modifier combinations, custom tabs, draggable widgets, tiny controls, and unrestricted text input require explicit redesign for Bedrock controllers.

Candidate interactions include item use, sneak-plus-use, hold activation, sequential/radial selectors, stable forms, in-world controls, NPC dialogue, books, containers, entity interaction, hotbar mode switching, and scoreboard/boss-bar feedback.

Every redesign records the original task, action frequency, replacement mapping, cancel/back behavior, focus order, labels, feedback, accidental activation risk, latency, multiplayer ownership, and fallback when a form is unavailable. It is scored for usability, interaction speed, discoverability, safety, multiplayer behavior, and accessibility/platform compatibility where applicable.

Controller review requires actual controller execution. A keyboard/mouse test or successful form creation is not sufficient. Benchmark checklists remain `UNVERIFIED` until executed.
