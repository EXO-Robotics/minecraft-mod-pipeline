# Known limitations and non-claims

- Initial authentic-pattern Fabric and Forge 1.7.10 source fixtures exist, but they do not establish complete loader support.
- Fabric/Forge metadata inventory remains distinct from behavior extraction.
- Compiled-JAR parity is proven only for the controlled fixture vocabulary.
- Initial `MARKETPLACE_ADDON_STABLE`, data-only, symbol/version, clean-output, and fail-closed trigger checks are unit tested; catalog completeness and runtime qualification are not proven.
- Event registration improvements are statically tested, but real Minecraft action adapters remain unverified.
- Marketplace package separation is unit tested; no Creator Tools-plus-client qualification of Benchmark A exists.
- Creator Tools policy, rights, static performance, persistent migration, and project-operation primitives are present; live tools, measured runtime budgets, complete project operations, and full MCP transport remain incomplete.
- Existing BDS evidence is server diagnostic evidence only.
- No local Windows, Realm Windows, PS4, PS5, Xbox One, or Xbox Series benchmark is claimed here.
- Benchmark A is a specification scaffold, not a completed Add-On.
- Benchmark B has no selected or rights-cleared real mod.
- No Marketplace submission or approval is claimed.

Complex Java rendering, mixins, coremods, native libraries, arbitrary networking, dimensions, vehicles, and GUIs may require redesign or remain unsupported. Every such result must be feature-specific and evidence-backed.
