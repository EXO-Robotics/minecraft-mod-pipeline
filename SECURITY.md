# Security and rights boundary

This project coordinates local AI work; it does not grant rights to inspect,
adapt, redistribute, commercialize, or publish any mod or asset. Operators must
record those permissions separately and stop when authority is absent or
conflicting.

Production lanes must receive sanitized contracts only. Raw Java evidence,
private oracle cases, source-specific identifiers, credentials, and control
references must not enter production repositories, prompts, caches, artifacts,
or Git history.

The included macOS sandbox launcher is defense in depth, not a universal
security boundary. Review the generated profile and process receipt on the
actual host. Docker/BDS, desktop-client, console, Realm, controller,
split-screen, Marketplace, and release gates remain separately owned.

Report vulnerabilities privately to the repository owner. Do not include
third-party mod contents or credentials in a report.
